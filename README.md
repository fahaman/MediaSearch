# MediaSearch

A modern, responsive, and optimized visual media search application built with React, Redux Toolkit, and Tailwind CSS. Explore high-resolution royalty-free photos, 4K videos, and trending GIFs from Unsplash, Pexels, Tenor, and Pixabay.

## Features
- 📷 **Photos Search**: High-resolution photos powered by Unsplash & Pixabay APIs.
- 🎥 **Videos Search**: 4K stock videos powered by Pexels & Pixabay APIs.
- 👾 **GIFs Search**: Animated GIFs powered by Tenor & Giphy APIs.
- ❤️ **Collection Management**: Bookmark and manage saved media assets stored in Redux Toolkit state & localStorage.
- 📱 **Responsive Design**: Mobile-friendly layout using a custom warm palette.
- ⚡ **Optimized State Caching**: Redux Toolkit `createAsyncThunk` caching to prevent redundant API network requests.
